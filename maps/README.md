# Импорт путеводителя в Google My Maps

Финальные файлы пересобираются командой `python3 map_export.py` из корня проекта. Главный файл `all-places.csv` содержит все полезные поля вместе: `location`, `name`, `description`, `city`, `days`, `status` и источниковые подробности. `location` содержит известные координаты `lat,lng`, иначе английское название + город + адресный ориентир. Импортируйте этот CSV и выберите `location` как колонку расположения, `name` как заголовок.

Для отдельных слоёв доступны CSV по городам: `sochi-and-transit.csv`, `bangkok.csv`, `phuket.csv`, `kuala-lumpur.csv`, `tashkent.csv` (не более пяти слоёв). В них те же поля, включая описание.

`all-places.kml` и пять городских KML содержат все точки с координатами. Генератор использует 57 записей `geocoded-checked.json` и три отдельные точечные привязки с URL источников. Проверенные Google-геокодированные точки по cache вручную проверены пользователем только на соответствие границам региона; это не подтверждение адресного номера здания. `coverage.json` сохраняет происхождение координат и оставшиеся пропуски.

KML оформлены цветом города; отели выделены золотым, альтернативы серым. Описания меток содержат только название, город/дни и краткое описание, без служебных полей. При обновлении слоя выбирайте reimport/replace из KML: CSV-загрузка адресов повторно запускает геокодирование.

Отели отдельно включены как реальные именованные места, поскольку в itinerary они заданы обычной строкой: «У Аэропорта», Ramada Plaza, INNSiDE, Wyndham Garden Naithon, Amora Beach Resort и ExpressionZ. Координаты/точные адреса добавляются только при наличии в каталоге. Для остальных Google Maps получает название и английский город; проверьте предложенное совпадение при импорте. Неразрешённая ночь в Москве и домашний адрес не превращены в точки.

Тур `sputnik-phi-phi-50276` исключён из геокодируемых точек: это туроператорский продукт, не самостоятельный объект посещения; поиск мог бы поставить маркер на офис. Причина записана в `coverage.json`.

На компьютере откройте My Maps, создайте карту и слой, нажмите **Импорт**, загрузите CSV и назначьте `location` для позиции, `name` для заголовка. Официальная [справка по импорту](https://support.google.com/mymaps/answer/3024836?hl=ru). My Maps недоступен как отдельное мобильное приложение; существующую карту можно просматривать в Google Maps под тем же аккаунтом. Справка: [Android](https://support.google.com/mymaps/answer/3024836?co=GENIE.Platform%3DAndroid&hl=ru), [iPhone/iPad](https://support.google.com/mymaps/answer/3024836?co=GENIE.Platform%3DiOS&hl=ru).
